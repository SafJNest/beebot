# Database files

- [SQL](sql/) contains MariaDB schemas and migrations. `auth/`, `berbit/` and
  `spotify/` are separate catalogs.
- [NoSQL](nosql/) contains MongoDB operations and index scripts.
- [R2](r2/README.md) describes the Cloudflare object key layout used by Beebot.

The files define schemas and operational changes. The application does not run
these SQL or MongoDB scripts automatically.
